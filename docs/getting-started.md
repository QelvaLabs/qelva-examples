# Getting Started with Qelva Examples

This repo shows how to talk to Qelva-core from small, focused programs.

## 1. Run Qelva-core backend

```bash
git clone https://github.com/QelvaLabs/Qelva-core.git
cd Qelva-core
npm install
npm run dev:backend
Run a Node example
git clone https://github.com/QelvaLabs/qelva-examples.git
cd qelva-examples/examples/node-basic-intent
npm init -y
npm install typescript ts-node
npx ts-node index.ts
